Ad-Block & DNS Filtering

Downloads blocklists (hosts files or plain domain lists), dedupes them, and serves the result from a dedicated, frfw-managed DNS resolver (dnsmasq). Each category is kept as its own list, so blocks and counts can be told apart. Optionally also pushes a small "critical" subset of the base list into the existing Phase 4 XDP kernel filter.
